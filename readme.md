# Instrucciones para puesta en funcionamiento

1. Clonar el repositorio
2. Copiar el archivo de configuración `config.example.js` -> `config.js`
3. Editar el archivo `config.js` para colocar los datos necesarios: puerto y conexión a la BDD
4. Instalar dependencias: `npm install`
5. Iniciar la aplicación: `npm run dev`
